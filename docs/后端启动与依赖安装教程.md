# 后端启动与依赖安装教程

本文档介绍停车楼系统后端的依赖安装与启动步骤。

## 1. 后端概览

两个工程在桌面上的位置（注意：后端在 `parking_system`，前端在 `parking-system-frontend`，是**两个不同的文件夹**）：

```
C:\Users\27657\Desktop\
├── parking_system\                ← 后端（Python Flask，本文档的主角）
│   ├── app.py                     ← 启动入口
│   ├── requirements.txt           ← 依赖清单
│   ├── init_data.py               ← 数据库初始化脚本
│   └── instance\parking.db        ← SQLite 数据库
└── parking-system-frontend\
    └── parking-system\            ← 前端（Vue，依赖清单是 package.json）
        ├── docs\                  ← 本文档所在位置
        └── server.js              ← Node 模拟后端（备选方案）
```

| 项目 | 说明 |
| --- | --- |
| 后端目录 | `C:\Users\27657\Desktop\parking_system`（与前端项目 `parking-system-frontend` 平级） |
| 技术栈 | Python Flask 3.0 + Flask-SQLAlchemy + SQLite + paho-mqtt（可选） |
| 端口 | **5000** |
| 数据库 | SQLite，文件位于 `parking_system\instance\parking.db` |
| 前端对接 | 前端 `vue.config.js` 将 `/flask` 请求代理到 `http://127.0.0.1:5000` |

> 另外前端项目根目录还有一个零依赖的 Node.js 模拟后端 [server.js](../server.js)，仅用于无 Python 环境时演示，见 [第 7 节](#7-备选方案nodejs-模拟后端)。

## 2. 环境要求

- **Python 3.8 及以上**（本机已装 3.14.6 ✓）
- **pip**（本机已装 26.1.2 ✓）

验证环境：

```powershell
python --version
pip --version
```

> 若提示 `python` 不是可识别的命令，说明 Python 未加入 PATH，请重新安装 Python 并勾选 **"Add Python to PATH"**。

## 3. 安装依赖

### 3.1 进入后端目录

```powershell
cd C:\Users\27657\Desktop\parking_system
```

### 3.2 （推荐）创建虚拟环境

虚拟环境可以把后端依赖与系统 Python 隔离，避免污染全局环境：

```powershell
# 创建虚拟环境（只需执行一次）
python -m venv venv

# 激活虚拟环境
venv\Scripts\Activate.ps1
```

激活成功后，命令行提示符前会出现 `(venv)` 字样。

> PowerShell 若报错"禁止运行脚本"，先执行一次：
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

### 3.3 安装依赖包

依赖清单见 [requirements.txt](../../parking_system/requirements.txt)：

```
flask==3.0.0
flask-sqlalchemy==3.1.1
flask-cors==4.0.0
paho-mqtt==1.6.1
```

安装命令：

```powershell
pip install -r requirements.txt
```

国内网络建议使用清华镜像源加速：

```powershell
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

安装完成后可确认：

```powershell
pip list | Select-String "flask|sqlalchemy|paho"
```

## 4. 初始化数据库（首次运行）

首次运行（或删除了 `parking.db` 之后）需要执行一次初始化脚本，它会自动建表并填充演示数据（420 个车位、车辆、设备、能耗记录等）：

```powershell
python init_data.py
```

执行成功后会在 `instance\` 目录下生成 `parking.db` 文件。

## 5. 启动后端

```powershell
python app.py
```

看到如下输出即启动成功：

```
 * Running on http://0.0.0.0:5000
```

**验证接口**，浏览器或 PowerShell 访问：

```powershell
# PowerShell 验证
Invoke-RestMethod http://127.0.0.1:5000/api/hello
```

正常返回：

```json
{ "code": 200, "message": "停车楼系统启动成功！", "data": "Hello Parking System" }
```

常用接口快速测试：

| 接口 | 说明 |
| --- | --- |
| `/api/hello` | 健康检查 |
| `/api/spots` | 车位列表（支持 `?floor=` 按楼层过滤） |
| `/api/devices` | 设备列表（支持 `?type=`、`?floor=` 过滤） |
| `/api/energy/24h` | 24 小时能耗记录 |
| `/api/events` | 告警/事件列表 |

> 后端以 `debug=True` 启动，修改代码后会自动重载，无需手动重启。

## 6. 常见问题

### 6.1 端口 5000 被占用

报错 `OSError: [WinError 10048]`。查找占用进程并结束：

```powershell
netstat -ano | findstr :5000
taskkill /PID <上一步查到的PID> /F
```

### 6.2 pip 安装速度慢或超时

使用镜像源（见 [3.3](#33-安装依赖包)），或配置全局镜像：

```powershell
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 6.3 启动后报"数据库表不存在"

说明 `parking.db` 缺失或已损坏，重新执行初始化：

```powershell
python init_data.py
```

### 6.4 MQTT 相关报错

无需 MQTT 服务器。`app.py` 中 MQTT 客户端初始化代码默认已注释，不影响任何功能。

### 6.5 前端请求不到后端

- 确认后端已启动且端口为 **5000**；
- 前端代理目标可在 `.env.local` 中通过 `VUE_APP_FLASK_TARGET` 修改（默认 `http://127.0.0.1:5000`），改完需重启前端 dev server。

### 6.6 局域网队友无法访问

`app.py` 已监听 `0.0.0.0`，队友直接访问 `http://<你的电脑IP>:5000` 即可；若仍不通，检查 Windows 防火墙是否放行 5000 端口。

## 7. 备选方案：Node.js 模拟后端

前端项目根目录的 [server.js](../server.js) 是一个与 Flask 接口兼容的 Node 模拟后端，**无需安装任何依赖**，仅需本机装有 Node.js：

```powershell
cd C:\Users\27657\Desktop\parking-system-frontend\parking-system
node server.js
```

输出 `停车楼后端已启动: http://127.0.0.1:5000` 即成功。适合快速演示前端页面，数据为随机 mock 数据。

## 8. 附：打包版 exe（免 Python 环境）

`parking_system\dist\parking_system.exe` 是 PyInstaller 打包的独立可执行文件，内置了 Flask 后端、前端页面和 SQLite 数据库，**双击即可运行，无需安装 Python**。演示/交付时可将其复制到任意 Windows 电脑使用。详见后端目录下的 `使用说明.txt`。
